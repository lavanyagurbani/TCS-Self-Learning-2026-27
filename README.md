# Theory of Computer Science – JFLAP Practicals

## Self-Learning Assignment | Academic Year 2026–27

This repository contains practical work completed using **JFLAP (Java Formal Languages and Automata Package)** as part of the Theory of Computer Science (TCS) self-learning assignment.

## Objective

The objective of these practicals is to understand and visualize important concepts of Theory of Computation, including finite automata, regular expressions, formal grammars, pushdown automata, Turing machines, and pumping lemmas.

## Software Used

- **JFLAP** – Java Formal Languages and Automata Package
- **GitHub** – For storing and organizing practical files

## How to Open JFLAP Files

1. Download and open JFLAP.
2. Select **File → Open**.
3. Choose the required `.jff` file.
4. View, edit, or simulate the practical.

## Learning Outcomes

Through these practicals, I learned how to:

- Design and simulate finite automata.
- Convert between automata, grammars, and regular expressions.
- Understand parsing techniques and context-free grammars.
- Explore pushdown automata and Turing machines.
- Study pumping lemmas and formal language properties.
- Use visual simulations to understand theoretical concepts.

## Conclusion

JFLAP provides an interactive way to learn Theory of Computation. These practicals helped me understand abstract concepts through graphical representations, simulations, and hands-on experimentation.
